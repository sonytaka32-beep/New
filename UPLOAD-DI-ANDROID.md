# Upload Shisui Calc 6.0 from Android

1. Download `shisui-calc-v6-mobile.zip` and extract it with ZArchiver.
2. Open https://github.com/sonytaka32-beep/New and select branch `main`.
3. Choose **Add file → Upload files**.
4. Upload all extracted contents, including `.github/workflows/`, `assets/`, `css/`, and `js/`.
5. Commit with message `Improve natural Susanoo chakra flames v6`.
6. Open Actions and wait for the build. Download the artifact using the existing name `shisui-calc-v3-debug-apk`.

Keep the folder structure. Do not upload the ZIP as a single file. The workflow is intentionally unchanged to preserve the successful build configuration.
